# VILOB Light V0.9A — 해군 기반 및 고대 연안 노선

이 릴리스는 V0.8J 본편에 항구, 첫 실물 함선·승무원·해상 항로, 초기 해군 AI를 추가합니다.

## 실행

- **단일 파일:** `VILOB-Light-V0.9A.html`을 브라우저로 열면 오프라인 실행할 수 있습니다.
- **GitHub Pages:** `VILOB-Light-V0.9A-GitHub-Upload.zip`의 **압축을 푼 파일 전부**를 GitHub Pages가 제공하는 같은 웹 루트에 업로드합니다. ZIP 파일 하나만 업로드하면 실행되지 않습니다. `index.html`과 `style.css`, `part-01.js` … `part-09.js`, **`part-09a.js`**, `part-10.js`, `editor.html`의 상대 경로를 유지하세요.
- **기존 세이브:** V0.8I·V0.8J 상태 이관을 지원합니다. 658년 대형 세이브를 사용하기 전에는 원본 백업을 별도로 보관하세요.

## 이번 버전의 실제 구현

고대 `목재 가공` 연구 → 해안 항구 Lv.1 → 유상 연안 노선 건조 (600G, 1 AP, 목재75, 철5, 공기90일) → 주민 8명 선원 모집 → 해상 항로 항해.

중세 항구 Lv.2·갤리선과 상위 항구·범선/증기선 유형을 정의했지만 화물·육군 수송, 해전과 봉쇄는 아직 없습니다. 신규 국가 AI는 바닷길을 사용할 수 있을 때 항구와 소수의 함선을 투자하여 시범 운용합니다.

상세 패치·검증 내역은 `PATCH-NOTES.md`에 있습니다.
